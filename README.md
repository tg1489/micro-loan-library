# Micro-Loan Tool-Library Directory

A modern, SEO-ready directory template for neighborhood tool-libraries, share-spaces, and tool co-ops. Find where residents borrow drills, saws, gardening gear for a small membership or donation.

🛠️📚🤝

## Features

- SEO-first markup with semantic HTML, meta tags, and Open Graph
- React 19.3.0 + React Compiler 1.0 (stable) via Babel preset
- Vite 8 build with TypeScript strict checks
- Searchable directory grid with lazy-loaded images
- Glassmorphism UI, responsive, accessible
- ESLint flat config with react-hooks, react-compiler, react-refresh

## Tech Stack

- React 19.3.0
- React Compiler 1.0 (stable, babel-plugin-react-compiler)
- Vite 8.3.0 + @vitejs/plugin-react 6.1.1
- TypeScript ~6.0
- ESLint 10 + typescript-eslint 8

## Getting Started

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Typecheck:

```bash
npm run typecheck
```

Lint:

```bash
npm run lint
```
